Mission

PHILOSOPHY

究極の理念

「障害の痛み」とは、「心の痛み」である。
私たちは、そのすべての痛みを取り除く（ToRerun）。

MISSION

果たすべき使命

「障害の痛み」とは、「心の痛み」である。

私たちは、そのすべての痛みを取り除く（ToRerun）。目に見えない困難に寄り添い、一人ひとりが自分らしく生きられる社会を創る。

VISION

目指す未来

生きづらさを抱えるひとが、
AIの力とクリエイティブで自立する。

孤独からも、理不尽からも、完全に解放される社会を創る。テクノロジーと創造性が、誰もを支える未来へ。

VALUE

日々の行動指針

「痛みに寄り添う」

目に見えない「心の痛み」に、誰よりも深く共感する。言葉にならない想いにも、常に真摯に向き合う。

ACTIVITY

活動内容

AI教育支援

AIリテラシーの向上を支援し、誰もがデジタル社会に参加できる力を育みます。

生成AI講座

ChatGPTなどの生成AIツールの実践的な活用方法を学べる講座を提供します。

SNS活用支援

SNSを安全かつ効果的に活用するスキルを身につけるための支援を行います。

デジタル活用支援

日常で役立つデジタルスキルの習得をサポートし、情報格差の解消を目指します。

生活相談

生活に関する悩みや困りごとに寄り添い、適切な支援につなげます。

健康支援

心身の健康維持・増進のための情報提供やプログラムを実施します。

交流イベント

障がいの有無を超えた交流の場を創出し、共生社会の実現を目指します。

地域活動

地域の方々と連携した活動を通じて、コミュニティの絆を深めます。

MESSAGE

代表メッセージ

代表理事 植原 武志

「誰もが自分らしく生きられる社会をつくりたい」——
その想いが、ToRerunの原点です。

私自身、福祉の現場で多くの方々と出会う中で、社会参加の機会が限られてしまう現実を目の当たりにしてきました。障がいがあっても、年齢を重ねても、どんな環境で育っても、一人ひとりには可能性があり、社会とつながる力がある。

AIやデジタル技術が急速に進化する今、テクノロジーの力を活用することで、これまで難しかった社会参加の形を実現できると確信しています。福祉の温かさとテクノロジーの可能性を掛け合わせ、新しい共生社会の姿を一緒に創っていきたい。

皆さまのご支援・ご参加を、心よりお待ちしております。
